# yapfeed

Yapfeed is a short-form, public-domain audio feed designed for distraction-free listening.

## Why yapfeed?
- **Efficiency**: Save time and reduce complexity in your workflow.
- **Reliability**: Built for consistency and long-term use.
- **Fast setup**: Get up and running in minutes.

[View yapfeed on GitHub](https://github.com/FishyDanny/yapfeed)

## Marketable Value Proposition
Yapfeed offers a curated, eyes-off listening experience, perfect for resting your eyes while enjoying high-quality, public-domain stories.
